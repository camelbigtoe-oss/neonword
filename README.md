# NEONWORD

Cyberpunk pixel word puzzle. Plain HTML/CSS/JS, no build step. Installable as an app (PWA) and works offline after the first visit.

## Run locally

```bash
python -m http.server 5173
```

Open http://localhost:5173. In Chrome or Edge, click the install icon in the address bar to add it as an app.

## Play on your phone

Host the folder on any static host (GitHub Pages, Netlify, Cloudflare Pages). Open the URL on your phone and choose "Add to Home Screen". A service worker needs HTTPS, so a plain file:// open will play but won't install.

## Files

- `index.html` – layout
- `style.css` – pixel UI and the 6 themes
- `app.js` – NEONWORD rules, hints, XP, credits, stats, and the game menu
- `links.js` – NEONLINK: sort 16 words into 4 hidden groups
- `links-data.js` – NEONLINK puzzles (edit to add more)
- `trace.js` – NEONTRACE: trace theme words as paths through a 6×8 letter board
- `trace-data.js` – NEONTRACE boards, generated by `node tools/make-trace.js` (add themes there)
- `lake.js` / `space.js` – NEONLINK lake scenes and the NEONTRACE space background
- `leaderboard.js` – online leaderboard (setup below)
- `words.js` – answer words and their clues (edit to add more)
- `bg.js` – animated pixel city background and particles
- `audio.js` – chiptune sound effects (WebAudio)
- `sw.js` – offline cache. Bump `VERSION` after changing files.

Each game has its own level (stored in `lv`); ◈ credits are shared.

## Leaderboard setup (one time)

The leaderboard (★ on the menu) keeps scores in a free Supabase project.

1. Make a free account at supabase.com and create a project.
2. In the project, open **SQL Editor** and run:

   ```sql
   create table public.scores (
     id uuid primary key,
     name text not null check (char_length(name) between 1 and 16),
     data jsonb not null default '{}'::jsonb,
     updated_at timestamptz not null default now()
   );
   alter table public.scores enable row level security;
   create policy "read scores" on public.scores for select to anon using (true);
   create policy "add scores" on public.scores for insert to anon with check (true);
   create policy "update scores" on public.scores for update to anon using (true) with check (true);
   ```

3. Copy the **Project URL** and the **anon public** key (Project Settings > API) into the two
   constants at the top of `leaderboard.js`.

Anyone with the app link can read and change rows, so share it with friends only.

## Notes

- Guesses not in `words.js` are checked against api.dictionaryapi.dev and cached. Offline, any guess is accepted.
- Progress is saved in the browser's localStorage.
